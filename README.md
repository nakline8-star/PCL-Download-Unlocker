##PCL-Download-Unlocker

什么是PCL-Download-Unlocker?
PCL-Download-Unlocker是用于解锁PCL2下载限制的工具，主要通过二进制补丁移除限制部分，且不破解任何功能此工具只移除下载限制。
为什么开发此工具?
因为我为PCL赞助过，我很讨厌这样一刀切的处理方式，我们从未做过任何违反法律法规的事情，这件事情伤害了很多无辜的玩家，但我会为此负责。

注意：不允许分发任何修补后的PCL2以及原版PCL2程序，不允许直接分发此工具，在使用前请对比MD5值防止工具被篡改。
